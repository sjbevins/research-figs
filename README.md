# research-figs

Figure hosting for the MIPT-QEC research project — measurement-induced phase transitions in
Watts-Strogatz random Clifford circuits and the quantum error-correcting codes they produce.

These PNGs back a Notion results dashboard (raw URLs used as image sources). Structure:

- `imi_profiles/`, `imi_profiles_symlog/` — I(A:R) vs |A| profiles, all four depth checkpoints
- `dcont_histograms/` — contiguous-distance distributions P(d*)
- `genweights_ridge/`, `genweights_ridge_symlog/` — generator-weight ridgelines
- `rate_distance/` — rate-distance landscapes

Each family is organized by checkpoint / system size. Regenerated from the analysis pipeline.
